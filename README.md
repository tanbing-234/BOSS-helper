# BOSS 求职助手

一个本地 Chrome Manifest V3 扩展。它从 BOSS 直聘当前选中的岗位中读取职位信息，根据简历和求职偏好执行硬性过滤，再通过兼容 OpenAI Chat Completions 的 API 生成匹配评分和定制招呼语。

## 当前能力

- 读取当前岗位的名称、薪资、城市、公司、招聘者和职位描述
- 按城市、最低薪资和排除关键词进行硬性过滤
- 使用简历对岗位做 AI 匹配评分，展示优势和风险
- 生成可编辑的定制招呼语
- 打开沟通窗口并填入招呼语
- 可选显示直接发送按钮，默认关闭
- 在 Chrome 本地记录已填入、已发送和已跳过的岗位
- 自动遍历当前职位列表，先评分再按用户设置的最低评分决定是否投递
- 识别页面左上角已保存的推荐岗位，并结合简历、个人优势生成可配置数量的岗位切片逐个搜索
- 自动投递时保持搜索结果主页面，在独立小窗完成立即沟通、填写和发送，完成后关闭小窗并返回原职位列表继续下一岗位
- 沟通小窗由内容脚本独立执行，兼容聊天页重新加载和小窗内 SPA 切换，不依赖侧边栏出现在小窗中
- 自动队列为每个岗位保存独立的岗位、评分和招呼语快照，弹窗和标签页切换不会覆盖正在投递的数据
- 自动投递和定时投递都不限制岗位数量，会分段滚动并等待懒加载，连续八次没有新岗位后再切换关键词
- 队列每次只读取并处理一个岗位，完成后重新读取列表，避免虚拟列表索引提前失效
- 支持按系统本地时间设置定时自动投递；停止会取消 AI 请求、消息等待和沟通小窗
- 自动发送完成后将企业名称、岗位名称和期望薪资加入可编辑白名单，后续扫描命中企业与岗位时不再投递
- 自动或定时任务完成、失败或由用户停止后弹出投递简报，汇总岗位、企业、薪资、工作内容与投递结果
- 自动解码 BOSS 自定义字体中的薪资数字，并迁移白名单内已经保存的乱码薪资
- 根据简历的技能、职责、项目、业务领域和可迁移能力生成 8-30 个带证据的岗位切片，默认搜索 16 个
- 提供聊天消息扫描、岗位档案检索和招聘热点问答 RAG；可根据简历生成可编辑问答库，并按策略回复、挽回或发送简历
- 支持右上角切换 BOSS 与智联招聘；智联模式只执行搜索、详情评分和立即投递，不生成或发送自定义消息，也不接入聊天系统
- 智联触发 EdgeOne 人机验证时暂停队列并等待用户手动完成，验证跳转后从当前岗位自动恢复，不尝试绕过验证码
- 智联按页码逐页处理岗位：当前页完成后点击下一页，下一页禁用后才切换搜索关键词；BOSS 继续使用滚动加载
- 设置页白名单支持导出 Excel 可打开的 CSV（含完整岗位 Base），并展示岗位名称词云和岗位 Base 关键词词云
- 岗位切片改为在设置页根据简历预生成并保存；BOSS/智联启动时直接读取缓存关键词，不再临时调用 AI 分析简历
- 成功投递由后台统一事务归档白名单和完整 JD；白名单与沟通知识库支持收纳和搜索，岗位/JD 合并词云提供更细粒度中文短语切片
- 投递简报记录逐条失败原因，成功岗位可弹窗查看完整 JD；JD 入库及 CSV 导出会清理“举报、微信扫码分享”等页面噪声，并优先使用详情页企业名称
- 侧边栏提供持久化运行日志，可查看搜索、分析、投递步骤和完整错误信息
- 运行日志支持导出 UTF-8 文本；岗位匹配采用学历向下兼容和工作年限少 1 年容差，避免因本科应聘专科学历岗位或轻微年限差距被机械跳过
- 自动跳过招聘者显示两个月以上未活跃或长期未登录的岗位

## 安装

1. 在 Chrome 地址栏打开 `chrome://extensions/`。
2. 打开右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本项目目录。
5. 点击扩展图标打开侧边栏，再点击齿轮进入设置。

修改代码后，在扩展管理页点击该扩展的刷新按钮。

## 配置

设置页需要填写：

- 兼容 OpenAI Chat Completions 的接口基础地址
- API Key 和模型名
- 简历全文与补充优势
- 目标城市、最低薪资、排除关键词等偏好

默认接口为 `https://api.openai.com/v1`。其他厂商需要提供兼容的 `/chat/completions` 接口，并支持 JSON 输出模式。
填写接口地址和 API Key 后，先点击“验证连接并获取模型”。插件通过 `/models` 验证接口，并在成功后显示该接口返回的模型下拉列表。

## 使用

侧边栏右上角可切换 `BOSS` 与 `智联`。BOSS 模式保留定制招呼和聊天 RAG；智联模式只进行岗位搜索、详情分析、评分和立即投递。

1. 打开 `https://www.zhipin.com/web/geek/jobs` 并登录。
2. 在左侧选择一个岗位，确认右侧已经显示完整职位描述。
3. 打开扩展侧边栏，点击“AI 分析当前岗位”。
4. 检查评分、风险和招呼语，按需编辑。
5. 点击“填入沟通框”或“直接发送”。插件会点击职位页的“立即沟通”，在确认弹窗中点击“继续沟通”，进入消息页后再写入定制内容。“直接发送”会在填入后等待 5 秒，再点击发送按钮；找不到按钮时使用 Enter 发送。

启用设置中的直接发送后，可在侧边栏启动“自动投递”。自动任务只处理单次上限内的岗位；岗位必须通过硬性筛选、达到“自动投递最低评分”且 AI 结论为“建议沟通”才会发送。任务可随时停止，并会跳过已有历史记录的岗位。

直接发送默认不会显示。只有在设置中明确启用后，侧边栏才提供该按钮。

## 注意事项

- BOSS 页面更新后，DOM 选择器可能需要调整，相关逻辑位于 `src/content.js`。
- 扩展不会处理或绕过验证码、账号风控和平台限制。
- AI 被要求不得虚构经历，但发送前仍应人工检查内容。
- API Key 保存在 Chrome 扩展的本地存储中，不会注入 BOSS 页面；使用共享电脑时不建议保存个人密钥。
